NATURE OF THE PROBLEM
=====================

These files exhibit a Windows Unicode filename encoding corruption:

1. The files appear in directory listings (visible through the glob tool and
   os.listdir in Python)
2. However, the files CANNOT be opened by ANY application or system tool:
   - Python (open, os.path functions)
   - PowerShell (Get-ChildItem, Copy-Item, File.OpenRead)
   - .NET Framework (FileInfo, FileStream)
   - Windows API (FindFirstFileW, ReadFile)
   - The DSH filesystem read tool

3. The corruption is caused by special Unicode characters in the filenames:
   - U+00A9 (©) COPYRIGHT SIGN (in file #1)
   - U+2019 (') RIGHT SINGLE QUOTATION MARK (in files #1, #2, #3)

4. The filenames appear to have been downloaded from Anna's Archive (a
   shadow library) and the Unicode normalization form used (likely NFD -
   decomposed form) is incompatible with Windows file operations.

5. The files are "phantom" files: they exist in the directory entry table but
   cannot be accessed through any normal file path operation.

   - Or manually rename the files after download using a tool that handles
